## 🌟 Executive Summary & Chapter Value

**Multiverse Code** was designed and developed to provide a cinematic, interactive, and production-grade event hub for Bennett University's annual flagship hackathon. Far surpassing standard form templates, the platform combines MCU-inspired aesthetics with real-time reactive architecture, attendee intelligence, and gate validation systems.

### 🎯 Key Architectural Deliverables
1. **🦸 Custom Avengers × GFG Bennett Insignia**
   - High-definition beveled metallic emblem integrating the Marvel Avengers "A", GeeksForGeeks `{ }` coding brackets, Bennett University crest geometry, and an animated Arc Reactor core.
2. **🎬 Cinematic Hero & Live Countdown**
   - Live ticking HUD countdown timer (Days, Hours, Minutes, Seconds) with direct social sharing beacons (WhatsApp, Twitter/X, LinkedIn, Telegram, and 1-click Link Copy).
3. **📋 Remodeled 3-Day Multiverse Timeline**
   - **T-Minus 2 Days**: Problem statements decrypted and published 48h prior to Round 1 Evaluation.
   - **Day 1 (10:00 AM IST)**: Grand Kickoff on Bennett campus & Round 1 Architecture Evaluation.
   - **Day 2**: Prototype Evaluation by Industry Evaluators & Final Pitching Round.
   - **Day 3**: Grand Finale, Infinity Gauntlet Ceremony & ₹1,50,000+ Prize Distribution.
4. **📝 Multiverse Registration Engine**
   - Full student validation with support for **B.Com**, CSE (Core, AI, Cyber, Data Science), ECE, and Biotech.
   - Year of study constrained to **1st Year, 2nd Year, 3rd Year, and 4th Year**.
   - **Mandatory GitHub & LinkedIn Profile Links** with URL verification.
   - Persona Archetype selection (Iron Man, Captain America, Doctor Strange, Black Widow, Thor, Hulk).
5. **📱 Real-Time Working QR Code Access Pass**
   - Client-side real-time QR generation (`qrcode`) encoding verified attendee data.
   - 1-click **"Save QR Pass Image"** for mobile gate check-in at Bennett University.
6. **🛡️ S.H.I.E.L.D. Admin Intelligence & Outreach Console**
   - Searchable real-time attendee directory with direct email outreach and 1-click copy.
   - **1-Click CSV Export** for external analysis in Google Sheets / Excel.
   - **Rapid Check-In Mode**: Scan or enter Ticket ID / Roll No to verify students at entry.
   - **Broadcast Dispatcher**: Urgent notifications sent directly to attendees by track.
   - **Automated Confirmations Log**: Real-time dispatch audit trail with visual email preview.

## 🛠️ Tech Stack & Dependencies

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion
- **Icons**: Lucide React
- **Graphics & Assets**: Custom SVG & High-Fidelity Photorealistic Visuals
- **QR Engine**: `qrcode` (Vector & Raster DataURI generator)
- **Archive Engine**: `jszip` (One-click full project packager)
- **Effects**: `canvas-confetti` (Celebratory Particle System)
- **Persistence**: Real-Time LocalStorage Engine with `BroadcastChannel` multi-tab sync

## 💻 Local Setup & Execution

### 1. Clone the repository:
\`\`\`bash
git clone https://github.com/romit-raj-datasc/Multiverse-Code.git
cd Multiverse-Code
\`\`\`

### 2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

### 3. Launch the development server:
\`\`\`bash
npm run dev
\`\`\`
Visit \`http://localhost:3000\` in your browser.

### 4. Build for production:
\`\`\`bash
npm run build
\`\`\`
